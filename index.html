Challenge 2: Read the Python Code

Text-Based Logic
game_score.py 
points = 10
bonus = 5

if points + bonus > 12:
    print("Level Up!")
else:
    print("Try Again")
Console: Ready
Q1: What message will appear on the screen when we run this code? (Click to check)
Answer: "Level Up!" (Because 10 + 5 = 15, which is greater than 12)
Q2: What happens if we change points = 10 to points = 6? (Click to check)
Answer: "Try Again" (Because 6 + 5 = 11, which is not greater than 12)
Q3 (Spot the Bug): Why will print(Level Up!) (without quotation marks) cause an error? (Click to check)
Answer: Text (Strings) in Python must be inside quotation marks "..." so Python knows it is text, not a variable!
